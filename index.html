1. Standard Inflow Query (Created into Queue)

SELECT Id, CaseNumber, Subject, Priority, Origin, CreatedDate, Status 
FROM Case 
WHERE OwnerId = '00G5g000003ABC1' 
AND CreatedDate = LAST_MONTH 
ORDER BY CreatedDate ASC

2. Case History Query (Reassigned / Picked Out of Queue)

SELECT CaseId, Case.CaseNumber, Case.Priority, Case.Origin, CreatedDate, NewValue 
FROM CaseHistory 
WHERE Field = 'Owner' 
AND NewValue = 'Admin Queue' 
AND CreatedDate = LAST_MONTH
